Warum diese Varianten?

Accessible Name, DOM-Text und value sind unterschiedliche Werte. TEXT prüft normalen Buttoninhalt; VALUE prüft input-Beschriftungen. scope grenzt doppelte Namen ein. Ein Index demonstriert Reihenfolge, ersetzt aber keine fachliche Begründung. Der PDF-Button erzeugt ausdrücklich einen POST.
