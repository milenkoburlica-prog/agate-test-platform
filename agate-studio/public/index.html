Experimental boundaries

          

            Recorder uses a custom DOM observer, not Playwright's private
            codegen internals. Accessible names are approximated during capture;
            all candidate locators are checked with Playwright for match counts.
            Automatic module grouping uses visible headings and OPEN steps;
            review SPA boundaries manually. Suggestions never silently heal a
            test. ARIA comparison is exact and has no wildcard support.
            Multi-tab actions, drag/drop and native file dialogs are not
            automatically recorded; UPLOAD paths must be supplied manually.
            Closed shadow DOM is unsupported.
          

          

            One local user, one project and one active target browser. Run tests
            against systems you are authorized to test. Traces and screenshots
            can contain application data.
